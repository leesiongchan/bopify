# Midnight Pressing

Replace Sleeve Notes with the recommended Midnight Pressing direction,
approved by the user with “ok” after the research and proposal.

The first screen uses near-black, an oversized BOPIFY masthead and the actual
glass player crossing its typography. The marbled record rotates continuously.
A saturated mint Cover Flow spread, an oversized vinyl close-up, a quiet lyric
passage, compact liner notes and an orange download finish create changes in
scale, density and color. Remove the fictional paper sleeve, framed desktop
mockup, repeated italic headlines and uniform feature table.

The alternative was Record Shop Poster: warm ivory, black typography, orange
blocks and an asymmetric product composition. Midnight Pressing was recommended
to give the app's glass and marbled vinyl more presence.

Use the actual app screenshot, including CSS crops for product details. Keep
HTML/CSS, relative URLs, no JavaScript or new dependencies, consistent SVG
icon sizes, and continuous rotation except under reduced motion. Cropped
animation must not create horizontal scrollbars. Every feature and requirement
must remain accurate: macOS 26+, Apple silicon, Spotify Premium, developer-app
setup and ad-hoc signing. Preserve existing download and repository links.
