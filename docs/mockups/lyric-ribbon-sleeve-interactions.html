Quiet chrome.

No X and no Hold button. The proposed native version uses a global show/hide shortcut, with the existing menu action as a fallback. This browser shortcut works only while this page is focused.

Reading is a gesture.

Wheel, trackpad, scrollbar, or keyboard scrolling enters manual reading. Playback continues. Sync lyrics appears in a reserved footer slot. There is no timed snap-back and scrolling never seeks the song.

Movement with a purpose.

The vinyl turns slowly during playback. Cues move upward; known next/previous song changes introduce the new identity from opposite directions. Reduce Motion stops rotation and sliding.

Design proposal, not production behavior. Original fixture words and artwork; Play demo advances one cue every four seconds without audio. Three logical lyric cues are emphasized in live mode; long lines wrap and can be read by scrolling. Native timing must follow the source timestamps. Browser scrolling and glass approximate the intended native behavior; native focus preservation and shortcut registration remain implementation work.
