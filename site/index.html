Getting set up +

Library access uses your own Spotify developer app.

  1. Download the latest DMG, open it, and drag Bopify to Applications.
  2. Open Bopify from the menu bar and sign in to Spotify.
  3. Create an app in the Spotify Developer Dashboard. Select Web API and add http://127.0.0.1:8898/callback as a redirect URI.
  4. In the developer app’s User Management, add your Spotify account’s name and email. Copy its Client ID into Bopify and authorize library access.
Opening the app for the first time +

The current release is ad-hoc signed and not notarized. macOS may ask you to approve opening Bopify in System Settings → Privacy & Security.
